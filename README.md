## 关于

本项目 Fork 自 [Trellis](https://github.com/mindfold-ai/Trellis)，一个面向团队的 AI 编码工作流框架。

在此基础上进行个人化改造，主要用于：

- **学习与研究** — 理解 Trellis 的架构设计与工作流理念
- **工作流实验** — 尝试不同的 AI 辅助开发模式和平台适配
- **个人使用** — 打造适合自己的开发节奏与工具链

> ⚠️ 这是一个个人学习项目，不保证稳定性，不接受外部贡献。如有需要请使用 [Trellis 官方版本](https://github.com/mindfold-ai/Trellis)。
